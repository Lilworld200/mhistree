## Configuration and owners

- `AI_PROVIDER=groq` selects Groq; absent provider defaults to Groq. Missing key fails closed. Local ignored environment files were updated only for provider selection; the existing key was neither displayed nor changed. Restart a running local server to load it. Hosted configuration/deployment is separate.
- `lib/ai/groq.ts` implements `AIGateway` using `openai/gpt-oss-20b` for chat, extraction, assessments, practitioner assistance, continuity and titles. Existing `AI_*_MODEL` values are Gemini-only and do not accidentally route Gemini model IDs to Groq. The older8B model is currently enterprise-only in Groq's catalog. Low reasoning effort, excluded reasoning output,1536 default completion tokens for ordinary text,4096 for structured JSON, and existing explicit smaller caller budgets conserve usage. Incomplete outputs fail rather than being published as complete facts. Context, current source rechecks and validation are retained; no silent source/history truncation was added.
- `lib/ai/groq-request.ts` owns fixed HTTPS endpoints, server Authorization,45-second deadlines, cancellation, no redirects/cache and exactly one attempt. No network/429/5xx retries or model/provider fallback. JSON response streaming is capped at256KiB; audio at4MiB. Errors never expose upstream messages, credentials or prompt text. Exact `model_terms_required` maps to configuration failure, with allowlisted diagnostics only.
- `speech/groq-gateway.ts` uses `whisper-large-v3-turbo` via multipart transient WAV and `canopylabs/orpheus-v1-english`/`hannah` via exact saved reply text and WAV. No additional recording stream or chunk fan-out. `speech/config.ts` selects the same configured provider, retaining the transcript receipt key requirement. `speech/server.ts` records the actual adapter transcription model and preserves authorization before/after provider delivery. Reviewed patient text alone enters extraction. Existing silence suppression, five-second auto-stop,60-second cap, cancellation, typed-message silence and current-access checked five-item memory-only playback cache remain unchanged.
- `GeminiGateway` and `GeminiSpeechGateway` remain for an explicitly selected `AI_PROVIDER=gemini` rollback with its own existing credentials/model settings. There is no automatic Gemini fallback. Prior Gemini-specific opt-in tests remain historical provider tests; use `tests/groq-live.test.ts` for this provider.
- `.env.example`, client-secret scanner, ai-chat README and feature/clinical maps document the switch. No SDK dependency or migration required. Speech setup failures leave written replies available.
